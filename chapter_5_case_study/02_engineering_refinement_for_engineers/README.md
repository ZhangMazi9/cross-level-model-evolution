This folder contains the engineer-facing RFLP refinement outputs: a readable report, a run summary, and a structured package.

| File | Purpose |
| --- | --- |
| `REFINEMENT_RUN_SUMMARY.md` | Refinement run summary, including inputs, outputs, and overall validation status |
| `landing_gear_run_20260718_235520_engineering_refinement_report.md` | Human-readable engineering refinement report |
| `landing_gear_run_20260718_235520_engineering_refinement_package.json` | Structured refinement package for downstream tools or engineering workflows |
| `ENGINEER_CONFIRMATION_RECORD.md` | Post-refinement engineering confirmation record based on the refinement outputs; downstream CAE/MBD construction starts after this confirmation |
