# Traceability Summary

This folder provides a compact traceability package for the landing-gear case study.

It documents the main generation and refinement chain through selected intermediate checkpoints, representative state traces, validation summaries, and integrity checksums.

## Included Summaries

| File | Contents |
| --- | --- |
| `rflp_flow_summary.json` | High-level RFLP flow stages, final public model locations, and validation status. |
| `engineering_refinement_summary.md` | Aggregated engineering-refinement counts, key optimization-relevant parameters, and human-check boundary. |
| `CHECKPOINT_INDEX.md` | Stage-by-stage interpretation and provenance of the selected evidence files. |
| `CHECKSUMS.sha256` | SHA-256 checksums for the checkpoint files. |
| `checkpoints/` | Curated requirement, functional, use-case, logical, logic-physics, physical, and validation artifacts. |

## Connected Deliverables

The checkpoint evidence connects directly to the three case-study deliverable groups:

- `../01_rflp_final_models/`
- `../02_engineering_refinement_for_engineers/`
- `../03_optimization_modeling_results/`
