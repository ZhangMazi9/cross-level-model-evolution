# Final RFLP Models

This folder collects the final landing-gear RFLP deliverables so users can find the model artifacts directly.

| RFLP layer | Folder | Key files | Purpose |
| --- | --- | --- | --- |
| Requirement | `requirement_model/` | `main_landing_gear_requirement.xl` | Landing-gear requirement model |
| Function / Use Case | `usecase_model/` | `main_landing_gear_usecase.xl` | Landing-gear use cases and functional scenarios |
| Logical | `logical_model/` | `system_code.xl`, `MainLandingGearDropTest.xl`, `MainLandingGearDropTest_architecture.json`, `MainLandingGearDropTest_logical_simulation_contract.json` | Logical architecture, drop-test logical model, and logical simulation contract |
| Physical | `physical_model/` | `LandingGearReduced.xl`, `XLanguage_LandingGear_Model_Description.md` | Reduced landing-gear physical model and model description |

The corresponding RFLP flow stages, intermediate checkpoints, and validation status are documented in `../90_traceability_summary/`.
