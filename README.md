# Cross-Level Model Evolution

This repository provides the research materials supporting the manuscript on cross-level model evolution from RFLP conceptual design to engineering refinement and optimization modeling.

## Manuscript Coverage

| Repository section | Manuscript section | Evidence provided |
| --- | --- | --- |
| `4_4_experiments/` | Section 4.4 | System-level comparison and JSON IR ablation experiments, including task definitions, configurations, evaluation criteria, aggregate statistics, paired comparisons, and publication figures. |
| `chapter_5_case_study/` | Chapter 5 | Landing-gear RFLP models, engineering-refinement deliverables, optimization models, stage-by-stage checkpoints, and validation traces. |

## Start Here

1. Open `4_4_experiments/README.md` for the two Section 4.4 experiments and their result files.
2. Open `chapter_5_case_study/README.md` for the landing-gear case-study evidence chain.
3. Open `REPOSITORY_CONTENTS.md` for a file-level guide to the complete repository.

## Main Evidence

- Cross-domain benchmark tasks with shared experimental controls.
- Multi-agent and single-agent system-level comparison results.
- Four-condition JSON IR and direct-XLanguage ablation results.
- Four-model pass-rate figure in PNG, SVG, and PDF formats.
- Final requirement, use-case, logical, and physical RFLP models for the landing-gear case.
- Engineering-refinement reports and structured deliverables.
- Optimization variables, objectives, constraints, model files, and validation reports.
- Nineteen curated process checkpoints with SHA-256 checksums.

## File Formats

The repository uses JSON and JSONL for structured models and task definitions, CSV for experiment and validation data, Markdown and text for reports, XLanguage (`.xl`) for executable model artifacts, and PNG/SVG/PDF for publication figures.
